# Захист лабораторної №1 — «Бібліотека»

## 1. Намір і критерії K1–K6

Мета — узгоджена ER-модель каталогу, примірників, читачів, видач і бронювань. [K1–K6](spec.md) визначають UUID-ключі, точні кардинальності, нормалізацію, прямий M:N, відповідність семи сутностей і 30 атрибутів та відтворення SVG/PNG на Node.js.

## 2. Результат аудиту

[Незалежний аудит](ai/independent-generation-audit.md) установив **0 підтверджених семантичних розбіжностей**. Первинна відповідь містить CSS після копіювання рендеру; код отримано пізніше, нормалізовану копію перевірено окремо. Це не побайтово підтверджений код першої відповіді. Три виправлені помилки не заявляються; буквальна вимога топ-3 залишається невиконаною та потребує рішення викладача щодо прийнятності нульового результату. Користувач підтвердив завершення аудиту; технічні перевірки виконав AI-помічник.

## 3. Власні доменні рішення та ADR

Підтверджені рішення: Book — конкретне видання, Copy — фізичний примірник для уникнення дублювання; максимум одне активне бронювання пари читач–книга зі збереженням історії; birth_year допускає NULL, коли рік невідомий. Інші атрибути обов'язкові, крім returned_at до повернення. Це рішення вимог, а не виправлені помилки AI. Погоджений spec збережено в [5b0a3f8](https://github.com/the1nurz/mavpz/commit/5b0a3f86852b4ae2054683c1272e44eea87de755).

[ADR-0001](adr/0001-mermaid-source.md) обирає Mermaid замість ручного рисунка; [ADR-0002](adr/0002-author-book-many-to-many.md) — прямий Author–Book M:N замість BookAuthor на ER-рівні; [ADR-0003](adr/0003-derived-availability.md) — обчислювану доступність та пріоритет черги замість збереженого available. Альтернативи й наслідки наведено в ADR.

## 4. Перевірки та докази

Відтворення: npm ci, npm run audit, npm test, npm run render. Перевірка без перезапису діаграм — npm run check. [Звіт перевірок](ai/verification-report.md) містить результати, версії та SHA. [Матеріали аудиту](ai/independent-generation-audit.md), [історія рішень](ai/audit.md) та [промпти](ai/prompts.md) розмежовують участь користувача й AI. Статичний аудит не доводить NULL, часові правила, умовну унікальність чи 3НФ на даних.
