# DEFENSE — Завдання 1: Домен і модель даних (ER)

Домен: **бібліотека**.

## 1. Намір і критерії

Описати дані бібліотеки (каталог, читачі, видачі, бронювання) як ER-модель,
з якої наступні завдання (вимоги → взаємодія → процес → архітектура)
беруть сутності. Критерії K1–K6 зафіксовані в `spec.md` (типізовані `id`,
кардинальності з мінімальними, 3НФ, M:N без спільної таблиці, однакові
імена полів, рендер = опис).

**Чому цей домен:** він має обидва випадки з вимог — чистий M:N без
атрибутів (Автор↔Книга) і зв'язки з власними атрибутами (Видача,
Бронювання). **Чому така нормалізація:** кожен факт зберігається один раз
(видавець — у `Publisher`, не рядком у `Book`; примірник відокремлено від
книги — книга одна, примірників багато); доступність для видачі виводиться
зі стану примірника та відкритих видач, а не зберігається окремим полем.

## 2. Ключові розбіжності, знайдені й виправлені

1. `Reader.id` був `int`, інші ключі `uuid` — K1.
2. Книга без авторів була допустима (`}o--o{`) — K2.
3. `Copy.status` змішував фізичний стан із доступністю, яку можна вивести
   з `Loan.returned_at` — K3.

Усі виправлення виконані через зміну spec/критеріїв і подальше оновлення
моделі, без ручного патчу діаграми.

## 3. Ключові рішення й альтернативи (ADR)

* `adr/0001` — Mermaid `erDiagram` замість PlantUML (нативний рендер у
  GitHub, без Java).
* `adr/0002` — Автор↔Книга прямим M:N, а не `BookAuthor`: зв'язок без
  власних атрибутів.
* `adr/0003` — доступність для видачі виводиться з `Copy.state` та `Loan`,
  а не зберігається (альтернатива `Copy.status` відкинута: два джерела правди).

## 4. Перевірка: узгодженість spec ↔ модель

Для проекту перевіряється узгодженість **spec ↔ модель**:

* `python tools/audit.py` → код виходу 0 (типи ключів, збіг назв полів);
* `python tools/render.py` перегенеровує `model/er.svg` з `er.mmd` — 7
  сутностей, 7 зв'язків збігаються зі списком у spec;
* ручне звіряння 7 зв'язків spec з кардинальностями діаграми.

Наступні завдання спираються на ці сутності й не повинні їм суперечити.

**Обмеження:** статичний рендер зроблено Graphviz-скриптом з `er.mmd`;
Mermaid-рендер — `model/er.md` на GitHub.
