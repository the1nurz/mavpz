## Майбутня структура

Створені три документи верхнього рівня та diagrams/README.md з 59 .mmd. SVG/PNG, tools/, test/, AUDIT.md та ai-log.md нижче залишаються планом наступних етапів:

```text
lab3/
  README.md
  spec.md
  traceability.md
  diagrams/                 # створено 59 .mmd та README.md з повним списком
    svg/                    # по SVG на затверджене джерело
    png/                    # по PNG на затверджене джерело
  tools/
    render-sequences.mjs
    check-sequences.mjs
    mermaid-config.json
  test/
    check-sequences.test.mjs
  AUDIT.md
  ai-log.md
```

Майбутні інструменти використовуватимуть Node.js та зафіксований Mermaid CLI, не змінюючи ER-render Завдання 1. Перевірка матриці має враховувати SC/рядок Examples і пояснені виключення, а не лише згадку ID.
