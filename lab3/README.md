## Майбутня структура

Наразі існують тільки три Markdown-файли верхнього рівня lab3; решта нижче — план:

```text
lab3/
  README.md
  spec.md
  traceability.md
  diagrams/                 # 59 майбутніх .mmd; точний перелік у spec.md
    svg/                    # по SVG на затверджене джерело
    png/                    # по PNG на затверджене джерело
  tools/
    render-sequences.mjs
    check-sequences.mjs
    mermaid-config.json
  test/
    check-sequences.test.mjs
  AUDIT.md
  ai-log.md
```

Майбутні інструменти використовуватимуть Node.js та зафіксований Mermaid CLI, не змінюючи ER-render Завдання 1. Перевірка матриці має враховувати SC/рядок Examples і пояснені виключення, а не лише згадку ID.

## Наступні етапи

1. Студент переглядає Етап 2, деталізацію 59 планів і відкриті питання. Рішення не підставляються автоматично.
2. Лише після окремої вказівки — створення затверджених .mmd за планом, без вигадування нових UC, прав чи гарантій доставки.
3. Окремий етап — інструменти перевірки повноти, синтаксису та рендер SVG/PNG.
4. Змістовий і візуальний перегляд, фактичні результати в AUDIT; студентські погодження лише за їх наявності.
5. Коміт/публікація/PR — тільки за відповідним дозволом.

DEFENSE для Завдання 3 — окремий Google Docs, який студент заповнює самостійно. Новий DEFENSE.md у репозиторії не створюється; успадкований файл Завдання 1 не змінюється.
