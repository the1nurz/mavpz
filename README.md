# Лабораторна робота №1 — Домен і модель даних (ER)

Предметна область — бібліотека: каталог книг, автори, видавці, примірники,
читачі, видачі та бронювання. Мета — узгодити специфікацію й ER-модель,
обґрунтувати ключі, кардинальності та нормалізацію й забезпечити
відтворювані перевірки та рендер на JavaScript (Node.js 22), без Python.

Це переробка раніше перевіреної лабораторної. Репозиторій фіксує реальні
етапи поточної роботи, рішення студента та використання AI.

## Поточний стан

Специфікація й ER-модель створені; студент переглянув критерії та доменні
правила. Зміна правила бронювання й уточнення черги зафіксовані в
[eec20c0](https://github.com/the1nurz/mavpz/commit/eec20c0a3be317592b826a3b89b251295eb9c8e7).
Три ADR прийняті студентом; підтвердження збережені в ai/audit.md.

JavaScript-аудит, package.json і 44 тести реалізовані та перевірені.
Mermaid-рендер, SVG/PNG, npm run check та DEFENSE.md створені.
Студент підтвердив особистий перегляд PNG, його структуру та обґрунтування
3НФ за прийнятими доменними припущеннями. Окремий перегляд SVG не підтверджений.
Історичні записи AI збережені; журнал промптів поки не є повним експортом
діалогу. Перед повним завершенням здачі залишаються PR, змістовне рев'ю
та посилання на PR у Classroom. Definition of Done здачі ще не завершений.

Робота ведеться в `fix/lab1-ai-review`; кожен змістовний етап проходить
перегляд перед комітом. Push та створення PR потребують окремого дозволу.

## Запуск аудиту й тестів

Потрібен Node.js 22.13 або новіший у межах версії 22, з npm у PATH.
Аудит і тести використовують стандартні модулі; для рендеру встановіть
зафіксовані залежності командою `npm ci`.

```sh
npm run audit
npm test
```

Аудит перевіряє таблиці атрибутів і зв'язків у spec.md та відповідність
Mermaid: назви, кількість, типи, PK/FK/UK, цілі FK, кардинальності,
підписи та дублікати. Код виходу 0 означає успіх структурних перевірок;
1 — невідповідність, помилку читання або непідтримуваний формат.

Підтримується формат поточної моделі: erDiagram, блоки сутностей,
атрибути з PK/FK/UK, зв'язки та коментарі %% на окремих рядках.
Нерозпізнані рядки не ігноруються. Інші конструкції Mermaid
потребуватимуть явного розширення парсера. Заголовки двох таблиць spec
є частиною формату автоматичного аудиту.

```sh
node tools/audit.js --spec spec.md --model model/er.mmd
```

Типові файли визначаються від каталогу скрипта; задані шляхи — від
поточного каталогу. Тести використовують копії в пам'яті та тимчасовому
каталозі, не змінюючи справжню модель.

Для K3 автоматично перевіряється лише структурна частина: відсутність
зайвих полів, зокрема похідної доступності Copy. Функціональні залежності,
3НФ, фактична унікальність даних, часові правила та черга бронювань
потребують ручної оцінки або майбутньої реалізації операцій. K6 цим
скриптом не перевіряється.

## Встановлення та відтворення діаграми

```sh
npm ci
npm run audit
npm test
npm run render
npm run check
```

Mermaid CLI 12.0.0 зафіксована в package.json, повне дерево залежностей —
у package-lock.json. Під час npm ci Puppeteer завантажує сумісний браузер
у .cache/puppeteer; потрібні доступ до мережі й дозвіл запускати headless
браузер. Не встановлюйте PUPPETEER_SKIP_DOWNLOAD, якщо браузера ще немає.
node_modules і .cache виключені з Git. Python та Graphviz не потрібні.

Рендер читає тільки model/er.mmd та tools/mermaid-config.json, спочатку
виконує структурний аудит, генерує обидва формати в тимчасовому каталозі,
перевіряє їх і оновлює результати лише за зміни байтів. Фіксовані seed,
стиль, шрифт і розмір забезпечують однаковий результат повторних запусків
у перевіреному середовищі. Інша ОС або набір шрифтів може вплинути на
геометрію; однаковість між різними ОС не гарантується.

npm run check запускає аудит, тести й новий рендер у тимчасовому каталозі.
SVG/PNG порівнюються побайтово зі збереженими артефактами; відсутній або
застарілий результат дає код 1 без перезаписування. Після свідомої зміни
моделі виконайте npm run render, перевірте діаграми й повторіть check.

Для перегляду відкрийте [SVG](model/er.svg) у браузері або
[PNG](model/er.png) у переглядачі зображень. SVG можна масштабувати;
PNG зручний для вставлення у звіт. Звірте сім сутностей, 30 атрибутів,
ключі й кардинальності зі spec. Візуальний перегляд і підтвердження 3НФ
студентом залишаються окремими ручними перевірками.

Документація інструмента: [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli).
