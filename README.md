# Лабораторна робота №1 — Домен і модель даних (ER)

Предметна область — бібліотека: каталог книг, автори, видавці, примірники,
читачі, видачі та бронювання.

Мета — підготувати узгоджену специфікацію та Mermaid ER-модель, обґрунтувати
ключі, кардинальності й нормалізацію та реалізувати перевірки і рендер
на JavaScript (Node.js 22), без Python.

Це переробка раніше перевіреної лабораторної. Новий репозиторій фіксує
поточні реальні етапи роботи й студентського аудиту AI.

Погоджені критерії K1–K6 та контракт моделі наведені у [spec.md](spec.md).
Розробка моделі та інструментів ведеться в гілці `fix/lab1-ai-review`;
автоматизація й остаточна документація ще не завершені.
