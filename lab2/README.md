## Перегляд і рендер діаграми

Відкрийте SVG у браузері й масштабуйте; PNG зручний для звіту.
Межа системи охоплює UC, актори розміщені зовні. У легенді наведено
наскрізні правила; деталі трасування є в коментарях `.puml` та матриці.

Команди нижче виконуються з кореня репозиторію. Потрібні Java 21,
Graphviz `dot` у PATH і PlantUML 1.2026.2. Завантажте JAR з
[офіційного релізу](https://github.com/plantuml/plantuml/releases/tag/v1.2026.2)
у `.cache/plantuml/plantuml.jar` або замініть шлях на свій:

```sh
java -jar .cache/plantuml/plantuml.jar -charset UTF-8 -checkonly lab2/diagrams/use-cases.puml
java -jar .cache/plantuml/plantuml.jar -charset UTF-8 -tsvg lab2/diagrams/use-cases.puml
java -jar .cache/plantuml/plantuml.jar -charset UTF-8 -tpng lab2/diagrams/use-cases.puml
```

Якщо `dot` не в PATH, задайте `GRAPHVIZ_DOT` повним шляхом до нього.
Перевірено з Temurin 21.0.12.1, Graphviz 16.1.0 і шрифтом Arial.
Інші шрифти або версії можуть змінити геометрію. SVG і PNG генеруються
з одного джерела; розміри полотен можуть відрізнятися через округлення.

## Запуск перевірок

Потрібні Node.js 22.13+ у межах версії 22 та npm у PATH.
Тести №1, ER-аудит і трасування не потребують встановлення залежностей:

```sh
npm test
npm run audit
node lab2/tools/check-traceability.mjs
node lab2/tools/check-uc10.mjs
git diff --check
```

Офіційний парсер Gherkin встановлюється окремо в ігнорований кеш,
без зміни залежностей лабораторної №1:

```sh
npm install --prefix .cache/gherkin --no-audit --no-fund @cucumber/gherkin@42.0.1
node lab2/tools/check-gherkin.mjs
```

Очікується: 9 історій, 27 унікальних визначень сценаріїв, 51 конкретний
випадок після Examples, 24/24 EARS. Скрипт також перевіряє граничний due_at
у SC-19 та його тег REQ-13. Синтаксис і компіляція Gherkin **не є
поведінковими тестами застосунку**: реалізації кроків немає.
44 тести `npm test` перевіряють наявний інструментарій №1.

Специфікацію перевірено друком Markdown → HTML → PDF у Chrome:
1 сторінка A4, поля 15 мм, Arial 11 pt, міжрядковий інтервал 1.22;
заголовок 15 pt, абзаци з відступом знизу 7 pt. Markdown сам по собі
не задає фізичної кількості сторінок; інший профіль друку може її змінити.

## Узгодженість і аудит

Джерела №1: [spec.md](../spec.md), [ER](../model/er.mmd),
[ADR-0003](../adr/0003-derived-availability.md). Збережено 7 сутностей,
30 атрибутів, 7 зв'язків, прямий Author–Book M:N, відмінність Book/Copy,
одну відкриту видачу, обчислювану доступність і чергу за reserved_at/UUID.
Бронюється книга незалежно від доступності; повторні операції окремі.

```sh
git diff 8f952ed --exit-code -- model spec.md adr
```

Команда має завершитися кодом 0. REQ-10 — структурний інваріант через
US-09, SC-11 та легенду; окремий UC для нього не вигадується.
Сервіс сповіщень є зовнішньою інтеграцією, а не новою сутністю ER.

AUD-01 усунуто в
[`9b02a0b3`](https://github.com/the1nurz/mavpz/commit/9b02a0b3f40c7aaf8f54e9cb46f1158aabc39192):
критерії та SC-19 тепер явно перевіряють дозволену рівність due_at і loaned_at;
трасування оновлено. Пізніші зміни після AI-CHECK і відомі розходження
spec зафіксовані в актуальному доповненні до аудиту від 24.10.2026.
